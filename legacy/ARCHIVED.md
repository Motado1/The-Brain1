# Archived — legacy web prototype

This directory holds the original **Next.js / Supabase / RAG web prototype** of The Brain. It has
been superseded by the native Rust engine in [`../engine/`](../engine/) and is **no longer
maintained**. It's preserved here only for historical reference — nothing in the active project
depends on it.

Moved here via `git mv` (history preserved) on 2026-06-15. The prototype's own README is
`README.md` in this folder.

> Note: `.env.local` here was committed to git history in the past. If it contained live Supabase
> or API keys, treat those as exposed and rotate them.
